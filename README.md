# Trading & Savings Dashboard V2

Versi upgraded dari dashboard sebelumnya.

## Fitur
- Dashboard modern responsive untuk HP/laptop.
- Modal awal, saldo trading, net profit, target harian 5%.
- Konversi USC → USD → IDR menggunakan kurs Rp16.100/USD.
- Equity Curve dan Profit/Loss chart.
- Daily Trading dengan pencarian.
- Uang Masuk / Keluar: Deposit, Withdraw, cashflow net.
- Tabungan dengan target dan progress.
- Rekap bulanan.
- Quick Add menu.
- Export CSV untuk Trading/Cashflow/Tabungan.
- Dark mode tombol tema.
- Data tersimpan otomatis di browser dengan localStorage.
- Tidak membutuhkan backend untuk menjalankan versi ini.

## GitHub Pages
Upload `index.html`, `style.css`, dan `app.js` ke repository, kemudian:
Settings → Pages → Deploy from branch → pilih `main` dan folder `/root`.

## Catatan
Data localStorage hanya tersimpan pada browser/perangkat tempat web digunakan. Untuk sinkronisasi antar perangkat, tahap berikutnya dapat ditambah database + login.
